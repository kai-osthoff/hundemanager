# Teilprojekt 5: Erkennung von Heimtierausweis-Fotos (erster Entwurf) – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Beim Hochladen von Impfpass-Fotos schlägt die App Passnummer, Geburtsdatum und je Impfung „gültig bis“ vor – mit Bildausschnitt, Saskia bestätigt.

**Architecture:** `erkennung.py` trennt OCR (RapidOCR, optional) von der Auswertung (`auswerten(bloecke, …)`, reine Funktion, mit erfundenen Textblöcken testbar). Alles hängt an Beschriftungen (Merkmale, zweisprachig DE/EN), nie an festen Positionen. Werte = Text im Bereich unter einer Beschriftung bis zur nächsten; zerfallene Daten („27.02.“ + „26“) werden zusammengesetzt; leere Felder einmal vergrößert nachgelesen. Plausibilitätsprüfung entscheidet sicher/unsicher.

**Tech Stack:** rapidocr 3.9.2, onnxruntime 1.30.0 (Windows-Wheels cp311–cp314 geprüft), Pillow, Flask/Jinja.

## Global Constraints

- Windows 11 zuerst; RapidOCR fehlt → App läuft wie bisher (kein Vorschlag, kein Fehler).
- Nur Vorschläge, nie automatisch übernehmen. Unsichere Werte nicht vorausfüllen.
- Datenschutz: kein OCR-Volltext speichern; Tests nur mit erfundenen Daten; Kais Fotos nie ins Repo.
- „verw. bis“/„Exp.“ (Monat-Jahr) ist nie ein Datum.
- Ein atomarer Commit, Windows-Test grün, merge, release.

`zusammenfassen([ergebnis|None, …]) -> dict` mit `erkannt`, `vorschlag{feld: iso}`, `passnummer`, `geburtstag`, `zeilen` (+`seite`).
