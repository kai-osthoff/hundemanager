STARTANLEITUNG

1. Python installieren: https://www.python.org/downloads/
2. Flask installieren: pip install flask
3. Doppelklick auf START.bat
4. Browser öffnen: http://127.0.0.1:5000

OPTIONAL EXE:
Du kannst selbst eine EXE bauen mit:

pip install pyinstaller
pyinstaller --onefile app.py

Dann entsteht eine EXE im dist-Ordner.
