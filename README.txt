HUNDEMANAGER

STARTEN
1. Python installieren (einmalig): https://www.python.org/downloads/
   Beim Installieren den Haken bei "Add Python to PATH" setzen.
2. Doppelklick auf START.bat
   Beim ersten Start werden die nötigen Pakete automatisch installiert.
3. Der Browser öffnet sich von selbst: http://127.0.0.1:5000
   Das schwarze Fenster offen lassen, solange du mit dem Hundemanager arbeitest.

UPDATES
Gibt es eine neue Version, erscheint oben ein blauer Hinweis
"Neue Version verfügbar". Auf "Jetzt aktualisieren" klicken - fertig.
Unten auf der Seite kannst du mit "Nach Updates suchen" auch selbst nachsehen.

Vor jedem Update werden Datenbank und Programm automatisch gesichert.

DEINE DATEN
Alle Daten liegen in der Datei instance\hundemanager.db.
Sicherungen liegen in instance\backup\ (die letzten 20 werden aufbewahrt).
Für eine eigene Sicherung einfach den Ordner "instance" kopieren.

FALLS DOCH MAL ETWAS SCHIEFGEHT
- Hundemanager schließen (schwarzes Fenster schließen).
- Die gewünschte Sicherung aus instance\backup\ nach instance\ kopieren
  und in hundemanager.db umbenennen.
- Ein früherer Programmstand liegt als code_....zip ebenfalls in instance\backup\.
