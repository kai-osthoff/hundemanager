HUNDEMANAGER

STARTEN
1. Python installieren (einmalig): https://www.python.org/downloads/
   Beim Installieren den Haken bei "Add Python to PATH" setzen.
2. Doppelklick auf START.bat
   Beim ersten Start werden die nötigen Pakete automatisch installiert.
3. Der Browser öffnet sich von selbst: http://127.0.0.1:5000
   Das schwarze Fenster offen lassen, solange du mit dem Hundemanager arbeitest.

UPDATES
Gibt es eine neue Version, erscheint oben ein blauer Hinweis
"Neue Version verfügbar". Auf "Jetzt aktualisieren" klicken - fertig.
Unten auf der Seite kannst du mit "Nach Updates suchen" auch selbst nachsehen.

Vor jedem Update werden Datenbank und Programm automatisch gesichert und
geprüft. Klappt die Sicherung nicht, wird das Update gar nicht erst gestartet.
Startet die neue Version nicht richtig, wird automatisch alles wiederhergestellt.

HAFTPFLICHT-NACHWEIS
In der Übersicht auf der Karte des Hundes bei "Haftpflicht" auf "Hochladen"
klicken, das PDF der Versicherung (oder ein Foto) hochladen, die erkannten
Angaben prüfen, speichern.
Alle Nachweise bleiben dauerhaft gespeichert und werden mitgesichert.

DEINE DATEN
Alle Daten liegen in der Datei instance\hundemanager.db,
die Nachweise im Ordner instance\nachweise.
Der Hundemanager sichert sie automatisch einmal täglich und vor jedem Update -
im Programmordner (instance\backup) und zusätzlich in
Dokumente\Hundemanager-Backups.
Unten auf der Seite unter "Sicherungen" siehst du alle Sicherungen, kannst
selbst eine anlegen ("Jetzt sichern") oder einen älteren Stand zurückholen
("Wiederherstellen"). Vor jedem Zurückholen wird der aktuelle Stand gesichert.

FALLS DOCH MAL ETWAS SCHIEFGEHT
- Startet der Hundemanager gar nicht mehr: In Dokumente\Hundemanager-Backups
  liegt in jedem Sicherungsordner die Datei hundemanager.db (deine Daten) und
  code.zip (das Programm). Bitte Kai Bescheid geben.
